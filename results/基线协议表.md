# 基线协议表（Baseline Protocol）

> 对应 P0-4：明确每个基线模型的代码来源、输入模态、种子、测试样本数与 AUPRC 口径。
> AUROC / AUPRC 均由统一脚本（`eval_metrics.py`，sklearn `roc_auc_score` / `average_precision_score`）按同一逐样本预测重算；
> 阈值依赖指标（F1/Sens/Spe/Acc）统一使用验证集 F1 最优阈值。种子统一为 42, 52, 62, 72, 82。
> 测试样本数 = 各数据集 test 子集（BioSNAP random 5,491；BindingDB 9,840；unseen-drug 5,290；unseen-target 4,903），见手稿 Table 1。

|---|---|---|---|---|---|---|

> **可追溯性说明**：除 DrugBAN/GraphBAN（本地拷贝含 `.git`，commit 可查）外，其余基线为官方仓库拷贝、未固定 commit。
> 严格复现如需逐版本可追溯，应在投稿前为每个基线补充官方 release/commit 标识或记录下载日期。
> **逐样本可得性（P0-1）**：仅 **SGBANDTI 与 DrugBAN** 归档了 5 seed 逐样本概率（`stats_input/`），其 AUROC/AUPRC 由统一脚本从逐样本重算（与手稿一致）；**其余基线仅归档 mean±SD**（`00_实验结果汇总.md`），逐样本概率未归档——待实验室补全后统一重算验证。阈值依赖指标（F1/Sens/Spe/Acc）仅对 SGBANDTI 采用验证集选优阈值，不用于跨模型主排名。
> **旧划分残留说明（2026-09-02）**：`comprare/experiment/` 内含旧划分（BioSNAP 5,493）运行的基线结果残留（**非正式结果**）。正式基线数字来自实验室/本地**新划分（5,491）**重跑，以 `00_实验结果汇总.md` / `results_manifest.csv` 为准。其中 **INGNN 与 GNN-CPI** 已在新划分（5,491）本地重跑并归档（INGNN 逐样本见 `per_seed/INGNN_biosnap/`；两者 AUROC 与手稿一致），其 `comprare/experiment` 旧残留已删除。
