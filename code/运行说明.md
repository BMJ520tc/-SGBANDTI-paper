# SGBANDTI 代码运行 / 复现说明

> 本仓库结构：主代码 `code/` + 数据 CSV `data/` + 对比基线 `baselines/` + 结果 `results/`。
> 代码默认配置 = 论文定版模型（BioSNAP random AUROC 0.9062 ± 0.0019）。
> 从 `code/` 目录运行，数据相对路径为 `../data/`；结果输出到 `../results/`。

## 一、环境

conda 环境 `sgbandti`（Python 3.10.20），见仓库根 `environment.yml` / `code/requirements.txt`。版本矩阵：

| 包 | 版本 |
|---|---|
| torch | 2.1.0+cu121 |
| dgl | 2.2.1+cu121 |
| torch-scatter | 2.1.2+pt21cu121 |
| torchdata | 0.7.1（新版本移除 dgl 需要的 datapipes） |
| dgllife | 0.3.2 |
| torch-geometric | 2.6.1 |
| rdkit | 2026.3.5 |

**踩坑**：默认 pip 源 torch 是 CPU 版，必须 `pip install torch==2.1.0+cu121 -f https://download.pytorch.org/whl/torch_stable.html`；torchdata 必须 0.7.1。

## 二、数据

- `data/`：BioSNAP random / unseen_drug / unseen_target + BindingDB random 的 train/val/test CSV，样本数与 `data/SPLITS_FROZEN.md` 一致（MD5 见该文件）。
- 划分说明：BioSNAP 去重 7 对后 27,457；7:1:2；冷启动按 canonical SMILES / 标准化蛋白分组，train/test 实体互斥。BindingDB 无重复对。
- **子图缓存**：首次运行前需重建（缓存不随仓库发布）：

```bash
python build_subgraph_cache.py --data biosnap --split random --hop 2
python build_subgraph_cache.py --data biosnap --split unseen_drug --hop 2
python build_subgraph_cache.py --data biosnap --split unseen_target --hop 2
python build_subgraph_cache.py --data bindingdb --split random --hop 2
```

## 三、运行命令（env `sgbandti`，从 `code/` 运行）

### 3.1 主实验
```bash
python main.py --data biosnap --split random --hop 2 --seeds 42,52,62,72,82
python main.py --data bindingdb --split random --hop 2 --seeds 42,52,62,72,82
python main.py --data biosnap --split unseen_drug --hop 2 --seeds 42,52,62,72,82
python main.py --data biosnap --split unseen_target --hop 2 --seeds 42,52,62,72,82
```

### 3.2 消融与 token-matched 对照
```bash
python main.py --data biosnap --split random --hop 2 --seeds 42,52,62,72,82 --ablation full
python main.py --data biosnap --split random --hop 2 --seeds 42,52,62,72,82 --ablation no_subgraph
python main.py --data biosnap --split random --hop 2 --seeds 42,52,62,72,82 --ablation no_ban
python main.py --data biosnap --split random --hop 2 --seeds 42,52,62,72,82 --ablation no_both
python main.py --data biosnap --split random --hop 2 --seeds 42,52,62,72,82 --ablation gcn_tokens
```

### 3.3 统计与一键生成
```bash
python eval_metrics.py ...          # 统一指标重算
python eval_with_ci.py ...          # bootstrap CI
python paired_bootstrap.py ...      # 配对检验 vs DrugBAN
python aggregate_seeds.py --data biosnap --split random --hop 2   # 5 种子聚合
# 一键生成链（数据校验 → manifest → 图表 → LaTeX），在仓库根运行：
bash code/run_all.sh --skip-latex
```

## 四、结果如何对应论文

所有正文表格、图表与 README 数字均来自 `results/results_manifest.csv`（唯一结果清单），由 `code/build_manifest.py` 从 `stats_input/`（SGBANDTI/DrugBAN 逐样本）与 `results/per_seed/`（SGBANDTI 各配置）自动生成；图表脚本（`generate_ablation_figure.py` / `generate_split_figure.py`）亦从该 manifest 读取，不手工硬编码。基线逐 seed 明细见 `results/tables/`。
